# templates 폴더

룬 감지와 화살표 판독에 쓰는 템플릿 이미지를 여기에 둡니다.
파일 이름은 기본 설정 기준입니다.

| 파일명 | 내용 |
| --- | --- |
| `rune.png` | 맵에 떠 있는 룬(또는 룬 위치를 알려주는 표식) |
| `arrow_up.png` | 룬 해제 화면의 ↑ 화살표 |
| `arrow_down.png` | 룬 해제 화면의 ↓ 화살표 |
| `arrow_left.png` | 룬 해제 화면의 ← 화살표 |
| `arrow_right.png` | 룬 해제 화면의 → 화살표 |

## 만드는 방법 (권장)

1. 게임을 **창모드**로 실행합니다. 창 크기는 이후에도 바꾸지 않는 것이 좋습니다.
2. 룬 헌터를 실행하고 `룬 해제` 탭으로 이동합니다.
3. 각 항목의 `화면에서 캡처` 버튼을 누르면 현재 게임 화면이 뜹니다.
   대상 부분만 드래그해서 선택하면 이 폴더에 PNG 로 저장됩니다.
4. 화살표 4종은 실제로 룬을 활성화한 상태(화살표가 떠 있는 순간)에 캡처해야 합니다.
   미리 룬을 하나 띄워 두고 캡처하면 편합니다.

## 잘 되는 템플릿의 조건

- 배경을 최소한으로 포함합니다. 화살표는 글리프 테두리에 딱 맞게 자르는 것이 좋습니다.
- 크기는 20~60px 정도가 적당합니다. 너무 크면 느리고, 너무 작으면 오탐이 늘어납니다.
- 애니메이션이 있는 대상(룬은 반짝입니다)은 가장 밝은 프레임보다 **평균적인 모습**을 고르세요.
- 해상도를 바꾸면 템플릿을 다시 만들어야 합니다. 여러 해상도를 쓰려면
  `룬 해제` 탭이 아니라 프로필 JSON 의 `rune.scales` 에 `[0.9, 1.0, 1.1]` 처럼 배율을 넣으세요.
- 투명(알파) 영역이 있는 PNG 를 직접 만들어 넣으면 마스크 매칭으로 전환됩니다. 이 방식은
  점수가 전반적으로 높게 나오므로 임계값을 0.9 이상으로 올려야 오탐이 없습니다.
  GUI 의 `화면에서 캡처` 로 만든 이미지는 알파가 없어 이 문제가 없습니다.

## 데모용 합성 템플릿

실제 스크린샷이 없어도 파이프라인을 확인할 수 있도록 합성 템플릿을 만들 수 있습니다.

```bash
python -m rune_hunter.tools.make_demo_templates
```

`templates/demo/` 에 생성되며, 데모 모드(`--demo`)에서는 이 이미지들이 자동으로 쓰입니다.
실전에서는 반드시 실제 게임 화면으로 만든 템플릿을 사용하세요.
